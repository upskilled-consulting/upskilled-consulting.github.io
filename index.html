Application

Custom Object Detector UI

This project allows our client to run object detection on massive drone "orthomosaics" — images typically too large to process, even with a powerful GPU — by wrapping a custom fine-tuned Faster R-CNN model and some API endpoints in a polished, modern interface. It handles tiled inference, automatic CRS reprojection, real-time progress updates, and interactive false positive removal, making the full pipeline user-friendly and accessible.
